# 徐可调研 05｜关键决策与行为模式

## 决策 1：从价值社交 ERA 切入，而不是从纯工具或纯内容切入

**时间**
- 2014 末组建团队
- 2015 年 ERA 获 Pre-A 融资的公开索引出现

**行为**
- 先做“认知盈余/技能交换/价值社交”类产品。

**说明**
- 她早期就不是做纯娱乐平台，而是偏“关系 + 价值流转”产品。
- 这和她后来不断谈“用户价值”“注意力价值”“财富机会”是一脉相承的。

**来源**
- https://www.sohu.com/a/220128394_358836
- https://m.chinaz.com/news/2015/1023/461178.shtml

## 决策 2：2017 前后转向区块链社交，而不是继续做普通中心化社交

**行为**
- 她在口述和访谈中都把转折点写成：
  - 做社交时发现需要区块链
  - 想解决用户数据与注意力价值被平台拿走的问题

**说明**
- 这是典型的“先有社会命题，再找技术壳”的决策方式。
- 她不是先从链出发找场景，而是先从场景痛点出发再给链找合理性。

**来源**
- https://www.sohu.com/a/220128394_358836
- https://m.ikanchai.com/pcarticle/273399

## 决策 3：技术上不做纯粹主义，而是接受混合架构

**行为**
- ONO 访谈里明确承认：
  - 不会把一切都上链
  - 社交数据仍在 AWS
  - 只有部分交易行为上链
  - 去中心化要与效率平衡

**说明**
- 这很关键。
- 她的决策风格不是“意识形态纯度第一”，而是“愿景在上，工程可落地优先”。

**来源**
- https://m.ikanchai.com/pcarticle/273399

**行为**

**说明**

## 决策 5：把叙事从“社交”平移到“全球资产/金融民主化”

**时间**
- 2024 年公开活动材料可见

**行为**
- UPTX 阶段，她把叙事重心从社交网络迁移到：
  - global asset trading
  - trust
  - transparency
  - financial democratization

**说明**
- 底层母题没变，壳子变了。
- 过去是“把话语权和数据权还给用户”，现在是“把财富机会还给更多人”。

**来源**
- https://www.doit.com.cn/p/524791.html

## 决策 6：2025-2026 在本地语料中公开推进“个人 IP / 直播 / 爱豆”转场

**行为**
- 本地 X 语料反复出现：

- 她拒绝被旧行业永久定义，而是把身份切换本身也做成叙事资产。

## 从这些决策中提炼出的稳定模式

### 1. 先抓大命题，再找技术/产品壳

- 社交阶段：用户权利
- 交易阶段：财富机会
- 社媒阶段：叙事主权

### 2. 愿景很大，但工程上不恋战纯度

- 能讲理想
- 也能接受混合方案、性能折衷、先变现再优化

### 3. 每次切赛道，都会保留“我不是 opportunist，我是在延续同一主线”的说法

- 这是她非常强的叙事自洽能力。

### 4. 被质疑时，不靠道歉求和，靠重建位阶和重放战绩反杀

- 这是她在本地长文本里最鲜明的行为模式。

## 局限

- 2020-2023 之间的完整决策链公开资料不足。
- 2025-2026 的大量判断来自本地一手语料，能证明“她这样说过”，但不自动证明相关事实本身都成立。
